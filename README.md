# Virtual Phone Launcher (تطبيق الهاتف الوهمي)

تطبيق لانشر وهاتف وهمي متكامل للأندرويد مبني باستخدام Jetpack Compose و Kotlin، يدعم معماريات الهواتف 32-بت و 64-بت، مع نظام تخزين دائم للبيانات عبر SharedPreferences.

---

## كيفية تصدير وتحميل ملف الـ APK عبر GitHub (بدون كمبيوتر):

1. ادخل إلى مستودع المشروع على **GitHub** من متصفح هاتفك.
2. اضغط على تبويب **Actions** في القائمة العلوية.
3. اضغط على سير العمل **Build and Export APK**.
4. اضغط على زر **Run workflow** ثم **Run workflow**.
5. بعد دقيقة أو دقيقتين ستكتمل المهمة وتظهر علامة صح خضراء (✅).
6. اضغط على المهمة وانزل لأسفل الصفحة عند قسم **Artifacts**.
7. اضغط على **VirtualPhone-Launcher-APK** وسيبدأ تنزيل التطبيق مباشرة إلى هاتفك لتثبيته.

---

## ميزات التطبيق:
- دعم كامل لمعمارية 32-بت و 64-بت (`armeabi-v7a` و `arm64-v8a`).
- حفظ دائم للبيانات لا يضيع عند إغلاق التطبيق.
- تطبيقات مدمجة: هاتف، رسائل، ملاحظات، كاميرا، حاسبة، متصفح، موجه أوامر (Terminal)، وإعدادات النظام.
- شريط حالة تفاعلي، لوحة تحكم سريعة، وشاشة قفل برمز PIN.
